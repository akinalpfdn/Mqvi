## v2.23.0

### New Features

- **voice**: when "Smooth Video" cannot start, the app now says so and shares with "Sharp Video"
  instead of switching silently. Previously the only clue was the codec line in the stream stats
- **voice**: screen shares that the server refuses, and shares that fall back, are recorded for
  the operator — so a problem on someone else's machine no longer has to be reproduced to be seen
- **security**: a cap on how many sockets one account may hold at once and how fast it may
  reconnect. Generous by default (10 sockets, 60 handshakes a minute) — a multi-device user will
  not notice, a script will

### Bug Fixes

- **voice**: a screen share is announced when the picture is actually on the wire, not when the
  source picker opens. Cancelling the picker no longer flashes a share to the whole channel
- **voice**: the "share your game" row no longer blinks in and out while you play — a single
  unreadable poll from the detector used to clear it and bring it back a second later
- **voice**: the right-click menu opens on your own share again, so the stats overlay can be
  switched off there. It was hidden along with the volume slider, which is the one control that
  is meaningless on your own stream
- **voice**: the engine choice is hidden on macOS and Linux, where the native capture helper
  cannot run. Picking "Smooth Video" there silently gave you "Sharp Video" on every share
- **e2ee**: sending two messages at once no longer loses ratchet state, and establishing a session
  is now one operation with the first encrypt — a conversation could previously end up unreadable
- **e2ee**: a conversation the client cannot decrypt yet is no longer hidden by initialisation state
- **chat**: mentions render as names in message previews instead of raw tokens
- **chat**: the emoji and GIF pickers stay on screen instead of running off the window edge
- **presence**: unfriending or blocking withdraws presence immediately, instead of leaving the
  other side subscribed until one of you reconnects
- **client**: every open conversation refills after a reconnect, not just the selected one
- **client**: open tabs are recovered and the socket reconnects when the network returns
- **client**: fixes to the unread snapshot, muted DMs, and reloads after a crash
- **uploads**: a failed storage-quota release is reported instead of being dropped, so quota can
  no longer drift upward on a partial failure
- **ws**: closes a data race in the hub

### Performance

- **voice**: screen sharing no longer stutters when a game saturates the CPU. The capture pump was
  competing with the game for scheduling; it now registers as a multimedia thread. Measured on
  Battlefield 6 at 95%+ CPU: worst delivered frame went from **8.8 fps to 28.1 fps**, and the
  stream holds its full bitrate instead of wandering
- **presence**: status changes go to the people they concern — servers you share, friends, DM
  partners — instead of every connected client
- **chat**: typing indicators no longer redraw the message list on every keystroke
- **bundle**: emoji data and the admin charts load on demand, cutting the main bundle from
  3.02 MB to 2.16 MB
- **members**: the member roster loads in two queries instead of one per member
- **unread**: an index on the unread fan-out

### Refactoring

- **client**: mutations in 12 components go through their stores instead of calling the API
  directly. **This is user-visible when the socket is down**: renaming a channel, kicking a member
  or changing server settings now updates immediately instead of waiting for an echo that may
  never arrive
- **server**: context keys moved to their own package, the six copies of the upload loop reduced
  to two, and the per-entity column lists deduplicated
- **servers**: `e2ee_enabled` can no longer be changed through the generic update path, so
  enabling encryption cannot skip the recovery-password prompt
