## v2.28.0

### New Features

- **voice**: "Smooth Video" now works on macOS 14 and later on Apple Silicon. The share is captured
  by the system and encoded in hardware, follows the shared window as it is resized, and ends
  quietly when the window or display is closed. A still window keeps a picture for viewers who
  join late
- **voice**: share audio now works on macOS 13 and later, with either mode. Sharing a window sends
  only that app's sound; sharing a screen sends everything except mqvi, so the call does not echo
- **voice**: on macOS, a missing Screen Recording permission now says where to grant it in System
  Settings, and modes the Mac cannot run are shown with the macOS version they need

### Bug Fixes

- **voice**: share audio that stops in the middle of a share is removed at once and you are told,
  instead of a silent track staying published
- **voice**: share audio that fails to start is stopped and reported instead of failing silently
- **voice**: on Linux, the screen picker no longer waits forever when the list of sources cannot
  be read

### Refactoring

- **capture**: each platform's share pipeline in the capture helper sits behind one interface,
  with no change in behaviour on Windows
