## v2.24.0

### New Features

- **voice**: a third noise reduction setting — Off, Standard, Strong. Strong removes what Standard
  structurally cannot: keyboard clatter, background speech, sudden noises. It costs some brightness
  in your voice, so it is a choice rather than the new default, and the setting says so before you
  pick it
- **voice**: Standard noise reduction is audibly better on steady noise — fans, hum, air
  conditioning — from a rebuilt RNNoise model. Nothing to switch on; everyone gets it
- **voice**: a denoiser that fails to start is now recorded for the operator instead of disappearing
  into a console nobody reads

### Bug Fixes

- **voice**: Strong falls back to Standard on audio hardware it cannot run on, and says so.
  Previously the microphone would have gone silent with nothing reported
- **voice**: the noise reduction slider no longer jumps back to a mode that was just refused
