## v2.27.0

### New Features

- **chat**: messages appear the moment you send them. If the connection drops, they are sent again
  automatically once it is back, and a message the server refuses stays in place with retry and
  discard
- **chat**: a message sent twice because a response was lost arrives only once
- **chat**: your own messages show a clock while they are being sent and a tick once they are sent
- **dm**: a second tick appears once the other person's app has received your message. Reading it
  changes nothing: there are no read receipts
- **mobile**: the iOS and Android apps open at once from what is stored on the device (your recent
  conversations, unsent messages and the tabs you had open) and catch up in the background. Signing
  out or switching accounts wipes it
- **mobile**: when your app is older than the minimum version the server asks for, an update prompt
  appears. It waits while you are in a call and never locks you out
- **mobile**: the app asks for a store review on the tenth time you open it
- **guide**: on Android, the back button closes a running guide tour first
- **errors**: crashes and unhandled errors in the app are reported to the server so they can be
  fixed. Personal details are scrubbed, no IP address is stored, and a signed-in app's reports are
  linked to its account, as the privacy policy describes

### Bug Fixes

- **voice**: "Smooth Video" shares no longer break into blocky patches when the picture changes
  suddenly, such as a game menu opening. Frames the app had already encoded were dropped before
  they were sent, and viewers decoded what followed against a picture they never received. Nothing
  is dropped silently now: a lost frame costs a brief pause instead of a corrupted picture. Full
  keyframes now come every 4 seconds, which leaves more of the bitrate for the picture itself
- **voice**: resizing a shared window no longer ends a "Smooth Video" share when other apps, such
  as OBS or Instant Replay, hold the GPU's encoder sessions
- **chat**: scrolling back through channel history no longer skips messages sent in the same second
- **chat**: messages deleted while you were offline disappear when the app reconnects
- **chat**: pressing Enter no longer sends the previous message again, and text typed right after
  Enter is kept
- **chat**: switching conversations while one is still loading no longer mixes up their loading
  state, reconnecting refreshes every message you have loaded rather than only the newest, and an
  open conversation keeps following new messages as they arrive
- **app**: switching accounts no longer shows the previous account's data
- **mobile**: the connection banner no longer shows on phones and tablets
- **mobile**: on Android, the layout follows the keyboard as it opens and closes, so the field you
  are typing in stays in view
- **admin**: screen-share failure reports in the admin logs name the actual cause. A harmless
  warning from earlier in the share no longer takes its place

### Refactoring

- **capture**: the screen-capture helper's encode loop is split into smaller parts, with no change
  in behaviour

### Other Changes

- **chat**: the message limit is now 15 messages per 7 seconds
- **deploy**: update the server before the apps. This release adds database migrations for
  idempotent message sending and DM delivery state
