## v2.25.0

### New Features

- **voice**: a deployment can now run more than one voice server, and a channel's call is placed on
  the one nearest the people in it. The first person into an empty channel picks, everyone after
  joins them, and the choice survives a server restart — so a channel is always one call in one
  place. With a single voice server nothing changes
- **admin**: platform administrators can set a region on each voice server, chosen from the set the
  server actually accepts rather than a list that could drift out of date

### Bug Fixes

- **voice**: on macOS, voice no longer breaks up while a game is running. Both what you hear and
  what others hear used to crackle and cut out the moment a game opened — even sitting in its main
  menu — and recovered only when you switched back to mqvi. There were two separate causes: the
  window being covered by a fullscreen game, and macOS Game Mode lowering the priority of everything
  except the game
